📖 Architecture Concept Explainer

The Windows Client Server natively reaches out to Azure DHCP. Because we are targeting enterprise topologies, we will leverage **PowerShell** to dynamically overwrite the active Ethernet adapter and force all traffic straight into our sabotaged Linux box.

Because Windows dynamically caches everything perfectly, breaking the DNSSEC chain generates a fatal unresolvable network timeout.
