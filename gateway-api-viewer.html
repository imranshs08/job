📑 SRE Cheat Sheet — Core Objects

Kubernetes Object Responsibility / Pattern
GatewayClass Template defining infrastructure implementation (e.g., Azure AGC, Envoy). Cluster scope.
Gateway Physical/logical load balancer containing Listeners (Port 80/443, TLS details). Typically managed by Infra namespace.
HTTPRoute Defines traffic routing (hostname, paths, headers) to backend Services. App Dev namespace.
ReferenceGrant Strict security boundary allowing Cross-Namespace attachments (e.g., App Route attaching to Infra Gateway).
Vendor Annotations Eliminated from Developer routes. Required ONLY on the Gateway object natively.
