🎯 ARCHITECTURE TOPOLOGY OVERVIEW & CORE OBJECTIVES
This master guide establishes an enterprise-grade perimeter security and global traffic routing topology. By positioning Azure Front Door (AFD)
Premium in front of Azure API Management (APIM), the architecture guarantees:
Global Traffic Acceleration:  Split-TCP Anycast edge routing for minimal latency across points of presence.
Layer 7 Edge Defense:  Web Application Firewall (WAF) with OWASP CRS Top 10, Bot Manager, and custom rate limiting.
Zero-Trust Perimeter Lockdown:  Direct access elimination via X-Azure-FDID  header checks, NSG Service Tags, and VNet Private Link.
Operational Observability:  KQL security queries, health probing ( /status-0123456789 ), and automated TLS lifecycle management.

PHASE 1: AZURE API MANAGEMENT (APIM) BASELINE SETUP Duration: 1-2 Days

global settings, custom domain certificates, and managed identity.

PHASE 3: ENTERPRISE WEB APPLICATION FIREWALL (WAF) SECURITY
Managed OWASP Core Rulesets, Bot Protection & Custom Rate-Limiting
PHASE 3: ENTERPRISE WAF POLICY & CUSTOM SECURITY RULES Duration: 2 Days
WAF Mode Assignment:  Attach a WAF Policy to Front Door Security Policies in Prevention Mode .
Managed Rulesets:  Enable Default Rule Set (DRS / OWASP Top 10) to guard against SQLi, XSS, and RCE attacks. Enable Bot

max 500 requests per 5 minutes per client IP).

PHASE 4: AFD TO APIM INTEGRATION & ZERO-TRUST PERIMETER LOCKDOWN
Enforcing X-Azure-FDID Header Validation, NSG Service Tag Filtering, and Private Link
PHASE 4: DETAILED INTEGRATION & PERIMETER LOCKDOWN MANUAL Duration: 1-2 Days
1. Header Lockdown via APIM Global Inbound Policy
Retrieve Front Door Header ID ( X-Azure-FDID ) from Front Door Overview.
In APIM, navigate to All APIs -> Inbound processing -> Policy editor  and apply:
<policies>
  <inbound>
    <check-header name="X-Azure-FDID" failed-check-httpcode="403" failed-check-error-message="Forbidden:
Direct access strictly prohibited" ignore-case="false">
      <value>YOUR-FRONT-DOOR-ID-HERE</value>
    </check-header>
    <base />
  </inbound>
</policies>
2. Network Security Group (NSG) Inbound Lockdown
Attach NSG to APIM Subnet: Source: ServiceTag / AzureFrontDoor.Backend , Protocol: TCP, Port: 443, Action: Allow.
Deny all other internet traffic.
3. Zero-Trust Private Link Setup (Front Door Premium)
Deploy APIM in Internal VNet mode with Private Link Service targeting internal load balancer. Enable Private Link in Front Door
Origin settings.
