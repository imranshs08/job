## Prompt Engineering Patterns for DevOps

```
Pattern 1: Role + Context + Task
"You are a senior DevOps engineer. Given this Kubernetes cluster 
running on EKS with [context], [specific task]..."

Pattern 2: Step-by-Step with Constraints
"Generate a Terraform module for [resource] with these constraints:
- Must use remote state
- Must include tagging
- Must follow [naming convention]
Step by step, explain each resource."

Pattern 3: Debug & Explain
"This Jenkins pipeline is failing with [error]. Here is the 
Jenkinsfile: [code]. Explain the root cause and provide fix."

Pattern 4: Compare & Recommend
"Compare [tool A] vs [tool B] for [use case]. Consider: 
cost, complexity, scalability, team size."
```
