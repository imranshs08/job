## Commands Cheat Sheet

```bash
# AWS CLI
aws ec2 describe-instances
aws s3 ls
aws iam list-users
aws eks list-clusters

# Azure CLI
az vm list -o table
az storage account list
az ad user list
az aks list -o table
```
